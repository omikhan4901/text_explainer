# Marketing kit (Windows preview)

Everything here describes what is built and tested today. Numbers come from
`docs/PROGRESS.md` ("Numbers"); update them when they change and don't round up.

- [Case study](case-study.md): one page.
- [Resume bullets](resume.md)
- [Facebook posts](facebook.md): a launch post, feature posts (private translation, the
  Word book, Look up, privacy) and a Bangla launch post, each with its screenshot
- [LinkedIn post](linkedin.md) (draft: post it when the first release is out)
- [Architecture one-pager](architecture.md)
- [Demo video script](demo-script.md) (record it when the first release is out)

Screenshots are in `docs/screenshots/`. Until the Windows release, they are of the real
interface running in a browser against the app's built-in mock, not of the installed app.

What is public: a free preview build (the README's Download link), rebuilt on every
change. **Not yet true, so not claimed anywhere:** a numbered release, users or download
numbers, translation quality per language (not measured yet), speed on a real laptop (the measured numbers are from a 4-vCPU CI runner; say so), macOS or Linux.

The logo (`src-tauri/icons/`, 1024 px master drawn by script): an ink square with a line of
text and one word highlighted in saffron, the app's own colours. It reads as the moment the
app is for: select a word, get help.
