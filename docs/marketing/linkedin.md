# LinkedIn post (draft; post when the first release is out)

I've been building Text Explainer: select hard text in any app, press one key, and a
clear version appears next to it. Contracts, papers, forms, medical letters.

It runs entirely on your laptop. No account, no cloud, nothing you read leaves the
computer. It's designed for ordinary machines: 8 GB of memory, no graphics card.

A few things I'm proud of:

• Small models sometimes switch to another language mid-answer. Instead of asking nicely,
  every request carries a grammar that makes the wrong writing systems impossible to
  generate.
• A "meaning check" flags any number, date or name the rewrite dropped or invented.
• The card never steals focus from the app you're reading in, and it closes with Esc.

Built with Rust, Tauri, React and llama.cpp. Open source:
github.com/omikhan4901/text_explainer
